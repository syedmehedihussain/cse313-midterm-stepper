# CSE313 Midterm Stepper

Live site: https://syedmehedihussain.github.io/cse313-midterm-stepper/

A step-by-step study guide for the CSE313 Compiler Construction midterm (syllabus topics 1-14).
Every method is a stepper: press Next and it does one small step, like a debugger.

- Ambiguous grammars and conversion, LMD/RMD and parse trees
- Left recursion removal (LRG to RRG) and left factoring (NDG to DG)
- FIRST and FOLLOW sets, LL(1) parsing table, stack parsing with a growing parse tree
- Solved past papers, a timed 30-mark practice paper, True/False drill, and a solver for any grammar

## How it is built

The steppers are generated by a small grammar engine, not typed by hand.

| Path | What it is |
|---|---|
| `src/engine.js` | FIRST/FOLLOW, LL(1) table, parser, left factoring, left recursion; each produces steps |
| `src/data.js` | grammars, derivations, hand-written steppers |
| `src/app.js` | rendering, steppers, practice paper, solver |
| `src/content.html`, `src/style.css` | lessons and styles |
| `tools/build.sh` | joins `src/` into one self-contained `index.html` |
| `tools/verify.py` | independent Python check of every answer |
| `tools/test-engine.js`, `tools/smoke.js` | Node tests for the engine and every widget |

Rebuild: `tools/build.sh` (writes `index.html` at the repo root, which GitHub Pages serves).
