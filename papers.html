3. [CO3] An ambiguous grammar is Non-deterministic Grammar (NDG). After converting it to Deterministic Grammar it is still ambiguous. What is the reason behind this? Is it possible to prove: "Determinism does not change ambiguity of a grammar." Justify with reasonings.[5]
Show model answer 3
Answer 3 [5]
WRITE THIS

Take E → E + E | E * E | id. It is ambiguous, and it is an NDG (two alternatives start with E). Left factor it:

E → E E' | id E' → + E | * E

The string id + id * id still has two leftmost derivations:

LMD 1: E ⇒ E E' ⇒ id E' ⇒ id + E ⇒ id + E E' ⇒ id + id E' ⇒ id + id * E ⇒ id + id * id

LMD 2: E ⇒ E E' ⇒ E E' E' ⇒ id E' E' ⇒ id + E E' ⇒ id + id E' ⇒ id + id * E ⇒ id + id * id

Reason: left factoring only removes common prefixes. It delays the choice between alternatives; it does not remove any alternative or any tree.

Proof (one-to-one mapping): each use of A → αβᵢ in the old grammar becomes A → αA' then A' → βᵢ in the new one, and back. So each parse tree maps to exactly one parse tree, and every string keeps the same number of trees.

∴ Yes, it can be proved: determinism does not change ambiguity. To remove ambiguity you must restructure the grammar with precedence levels.

Lose marks by: giving only the claim with no example; no derivations for the factored grammar.
